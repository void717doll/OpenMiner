# sounds

these wav files were converted from the supplied local luanti minetest_game default mod. they retain the licenses and authors listed in ../../docs/sound-assets.json. changes: ogg decoding, mono conversion, and resampling to 22050 hz signed 16-bit pcm wav.

see MINETEST-GAME-CREDITS.txt for upstream per-file attribution and original source links, and MINETEST-GAME-LICENSE.txt for upstream notices. the manifest distinguishes cc by 3.0, cc by-sa 3.0, and cc0 1.0 assets; a shared directory does not change an individual file's license.
